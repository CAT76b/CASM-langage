# CASM-langage
A custom programmation langage inspired by assembly.
Please bear with me – I’m working on this project all by myself

All instructions are in the txt file

The emulator is not finish

To use the compiler, write in the console:
  casm <file_name>.casm <file_name>.bin
To use the virtual machine, write in the console (warning! the virtual machine uses only little indian's binaries):
  casm_vm <file_name>.bin
To use the dump, write in the console (still!):
  casm_dump <file_name>.bin
WARNING! To use commands, you should have configured your computer's path.
